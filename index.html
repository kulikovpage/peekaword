A new word on your Lock Screen

Help

Add the widget

Lock Screen: touch and hold the Lock Screen → Customise → Lock Screen → tap below the clock → Peekaword.

Home Screen: touch and hold an empty spot → + or Edit → Add Widget → Peekaword.

The app shows the same steps as a video: Settings → How to add the widget.

Reminders

Settings → Reminders: turn them on and pick a time. At most one a day, and only when there is a reason.

Subscription

Optional: all learning is free and has no ads.

Manage or cancel: iOS Settings → your name → Subscriptions. After reinstalling: Settings → Support the project → Restore purchases.

Contact

Found a bug or a wrong translation? Open an issue on GitHub.

Допомога

Додати віджет

Екран блокування: затисни екран блокування → «Налаштувати» → «Екран блокування» → торкнись під годинником → Peekaword.

Робочий стіл: затисни порожнє місце → «+» або «Редагувати» → «Додати віджет» → Peekaword.

У застосунку ці кроки є у відео: Налаштування → «Як додати віджет».

Нагадування

Налаштування → «Нагадування»: увімкни й обери час. Не більше одного на день і лише коли є привід.

Підписка

Необов'язкова: усе навчання безкоштовне й без реклами.

Керувати чи скасувати: Параметри iOS → твоє ім'я → Підписки. Після перевстановлення: Налаштування → «Підтримати проєкт» → «Відновити покупки».

Зв'язок

Знайшов помилку чи неточний переклад? Напиши на GitHub.

Новое слово на экране блокировки

Помощь

Добавить виджет

Экран блокировки: зажми экран блокировки → «Настроить» → «Экран блокировки» → нажми под часами → Peekaword.

Рабочий стол: зажми пустое место → «+» или «Править» → «Добавить виджет» → Peekaword.

В приложении эти шаги есть в видео: Настройки → «Как добавить виджет».

Напоминания

Настройки → «Напоминания»: включи и выбери время. Не больше одного в день и только по делу.

Подписка

Необязательная: вся учёба бесплатна и без рекламы.

Управлять или отменить: Настройки iOS → твоё имя → Подписки. После переустановки: Настройки → «Поддержать проект» → «Восстановить покупки».

Связь

Нашёл ошибку или неточный перевод? Напиши на GitHub.

Nowe słowo na ekranie blokady

Pomoc

Dodaj widżet

Ekran blokady: przytrzymaj ekran blokady → „Dostosuj” → „Ekran blokady” → stuknij pod zegarem → Peekaword.

Ekran początkowy: przytrzymaj puste miejsce → + lub „Edycja” → „Dodaj widżet” → Peekaword.

W aplikacji te kroki są na filmie: Ustawienia → „Jak dodać widżet”.

Przypomnienia

Ustawienia → „Przypomnienia”: włącz i wybierz godzinę. Najwyżej jedno dziennie i tylko z powodu.

Subskrypcja

Opcjonalna: cała nauka jest darmowa i bez reklam.

Zarządzanie i anulowanie: Ustawienia iOS → Twoje imię → Subskrypcje. Po ponownej instalacji: Ustawienia → „Wesprzyj projekt” → „Przywróć zakupy”.

Kontakt

Añadir el widget
